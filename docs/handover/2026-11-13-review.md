# Handover: draft endpoints + 08 Review screen (M4, Daniil)

**From:** Daniil · **To:** Artem · **Date:** 2026-11-13

After Pursue, the user can now review the prepared application and mark it sent.

## api

- **Implemented from the contract:** `GET /v1/pipeline/:id` (`getPipelineItem`, **your route, it was missing**), `GET /v1/pipeline/:id/drafts`, `PUT /v1/drafts/:id`, `POST /v1/pipeline/:id/sent | registered | not-sent`, `GET /v1/pipeline/:id/event.ics`. `/v1/undo` now also reverts sent/registered.
- **Added to the contract** (`shared/review.ts`):
  - `GET /v1/review`: items in `ready_to_send`, newest first.
  - `GET /v1/pipeline/:id/review`: one call returning the item, the posting or event, ordered drafts and the special CV summary. `pipelineItemSchema` has no posting URL or CV fields, so this is a separate route.
- **Edit draft:** an atomic version check (stale → 409), `charLimit` → 400 `fields.body`; it sets `editedByUserAt`, bumps `version` and logs activity.
- **Mark sent** (jobs, `ready_to_send` only):
  - Sets `sentAt`, creates follow-up #1 due **+5 d**, sets `nextFollowUpAt` (shown as "Follow up on 18 Nov").
  - Undoable for 10 s; undo deletes the follow-up.
  - **Registered** is the same for events, without a follow-up.
  - **Not sent** goes back to `ready_to_send` and cancels follow-ups; it isn't undoable.
- **`.ics`:** RFC 5545 escaping and folding; a missing end time becomes 1 h.
- The special CV download reuses **your** `GET /v1/cvs/:id/download` (via `CvDownloadButton`).

## Web (`app/(app)/review/`)

- `/review` opens the first waiting item, or shows "No drafts to review"; `/review/[id]` shows one item. There is prev/next across waiting items.
- **Direct:**
  1. Download the CV (PDF/DOCX).
  2. Copy per draft, or Copy all.
  3. Open the job page.
  4. "I sent it" (confirm → toast with Undo).
- **Event:** open the page, add to calendar (.ics), "I registered".
- **Drafts** are editable, with a character counter, a 409 "Reload latest" message, and an **unsaved-changes guard** (`beforeunload` + an in-app link interceptor).
- The "What changed" list comes from the special CV.
- **Today links:** the "N ready to send" count links to `/review`, and a pursued card shows "Open in Review" (only for the 4 s it lingers).
