# Handover: Today endpoints + 07 Today screen + Run now (M3, Daniil)

**From:** Daniil · **To:** Artem · **Date:** 2026-11-13

After onboarding, the user now sees ranked jobs and events on Today and can run the agent on demand.

## api (`apps/api/src`, your architecture: ports → use cases → Drizzle repositories → routes)

- **`GET /v1/today`:**
  - Returns opportunities with feed status `new` or expired, joined with the job or event and the source name.
  - **Fit < 40 is hidden** (`MIN_FIT_ON_TODAY`); the contract doesn't specify.
  - Order is fit descending, then newest, with expired items last.
  - `counts` cover all visible items (for the chips). `readyToSendCount` comes from the pipeline.
- **Skip:**
  - Moves `new`/expired to `skipped`, writes an `activity` row (10 s undo window) and returns the undo token.
  - `company_excluded` also adds the company to `targets.exclusions`.
- **`POST /v1/undo`:** restores the previous values and stamps `undoneAt`, in one transaction (it also removes an exclusion that the skip added). Only skip is undoable. Unknown token → 404; expired or already undone → 409.
- **Pursue:**
  - Moves the card to `pursued`, creates a `pipeline_item` (`preparing`, the card's route) and enqueues `pack.prepare` (**no worker handler yet**, that's M4). Repeating it is safe.
  - Expired → 410 `posting_unavailable`.
- **Dismiss** (new/expired → `dismissed`) and **change route** (only to available routes).
- **Run now:**
  - `POST /v1/agent/runs` creates a manual `agent_run` and enqueues `agent.run`. It's rate-limited (`rateLimits.runNow`, 5/h); an active run → 409 `agent_busy`.
  - `GET /v1/agent/status` returns the current run, the last run, paused and next run.
- **New ports:**
  - `AgentJobQueue` (`enqueueAgentRun`, `enqueuePackPrepare`) is separate, so your `JobQueue` fakes still compile.
  - Also new: `TodayRepository` and `AgentRunRepository`.
  - `app.ts` now requires `agentJobs`, `today` and `agentRuns`; `test/test-app.ts` is updated.

## Web (`app/(app)/today/`)

- **Header:** the date and "N new, M ready to send". **Chips:** All/Jobs/Events with counts, disabled at 0 and hidden when that type is off in targets.
- **Card:** type, title, company or place, source, fit %, why, gap, route + reason.
  - **Pursue** shows "Preparing your pack…".
  - **Skip** is a split button with reasons and an "Other…" note. It leaves a collapsed "Skipped — Undo" row for 10 s, plus a toast with Undo.
  - **Expired** cards are greyed out with Dismiss only.
- **Run now** is in the header and the empty states. A progress panel ("Your agent is working…") polls `/v1/agent/status` every 2 s and refreshes Today when the run ends. There is also a failed-run banner.
- **Empty states:** before the first run, nothing new, all caught up.

## Not done / contract gaps

- `pursue` and `dismiss` aren't undoable (the contract returns no token).
- The pipeline item's `nextStep` and `specialCvId` are null until packs exist.
- No change-route UI.
